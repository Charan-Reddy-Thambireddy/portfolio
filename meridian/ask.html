Ask Meridian

Ask about a category, country or company. The answer is built only from Meridian sources you are subscribed to, and every figure links to its source.

How this demo works: it runs the retrieval half of retrieval-augmented generation (RAG) in your browser: find the question's entities, search the content, drop sources outside your subscription, then write the answer from those sources with a template. In production, the same retrieved sources would be passed to a large language model through the .NET API.

For example: How fast is tea growing in China? Which company leads bottled water in Indonesia?
